= Découvrez le tableau de bord Projets dans Workload Factory pour EDA
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Le tableau de bord Projets permet aux administrateurs informatiques et aux chefs de projet de visualiser comment les projets utilisent le stockage sur les systèmes de fichiers et volumes Amazon FSx for ONTAP. Il affiche les tendances d’utilisation du stockage afin que vous puissiez repérer les projets utilisant le plus de ressources, suivre les coûts et ajuster le stockage avant que des problèmes de capacité ou de performance n’affectent les simulations EDA.



[[how-the-projects-dashboard-works]]
== Fonctionnement du tableau de bord Projets

Le tableau de bord Projets affiche les métriques CloudWatch pour tous les volumes FSx for ONTAP liés à vos identifiants AWS. Vous pouvez créer jusqu'à cinq filtres à l'aide de balises AWS pour organiser et visualiser les données par projet, équipe, application ou autres catégories.

Le tableau de bord vous aide à :

* Planifiez la capacité et comprenez les coûts
* Utilisez les données pour décider comment affecter les ressources
* Repérez les projets qui utilisent beaucoup de ressources
* Suivez les coûts par projet ou équipe
* Ajustez le stockage avant que les problèmes ne surviennent


Pour une surveillance proactive des performances de latence, voir link:learn-latency-monitoring.html["Découvrez la surveillance de la latence"].



[[cloudwatch-metrics-collected]]
=== CloudWatch metrics collectées

Le tableau de bord collecte et affiche les indicateurs CloudWatch suivants :

* *Capacité provisionnée* : Métrique au niveau du volume représentant la capacité de stockage provisionnée.
* *Capacité utilisée* : Métrique au niveau du volume représentant le stockage utilisé.
* *Débit moyen/maximum* : Calculé comme la moyenne ou le maximum de la somme de DataReadBytes et DataWriteBytes sur la période spécifiée.
* *IOPS moyennes/maximales* : Calculées comme la moyenne ou le maximum de la somme de DataReadOperations, DataWriteOperations et MetadataOperations sur la période spécifiée.




[[custom-filters]]
== Filtres personnalisés

Les filtres personnalisés vous permettent d'organiser les données du tableau de bord en fonction du fonctionnement de votre organisation. Définissez des filtres par projet, équipe ou centre de coûts afin de trouver rapidement les données dont vous avez besoin sans avoir à trier des informations non pertinentes. Cela facilite la planification de la capacité, le suivi des coûts et la surveillance des performances.

Vous pouvez configurer jusqu'à cinq filtres personnalisés en fonction de vos balises AWS.

* *Nom de l'étiquette du filtre* : Le nom d’affichage qui apparaît dans le tableau de bord
* *Nom de la clé de balise AWS* : La clé de balise AWS réelle utilisée sur vos ressources
* *Type de sélection* : Sélection unique ou sélection multiple


Si vous ne configurez aucun filtre personnalisé, les filtres par défaut—système de fichiers, type de volume et plage horaire—resteront disponibles, de sorte que vous pouvez consulter et utiliser vos tableaux de bord.



[[aws-tags]]
=== Balises AWS

Les balises AWS sont des métadonnées pour vos ressources AWS. Elles vous aident à catégoriser vos ressources AWS de différentes manières, par exemple par projet, application ou unité commerciale.

Pour utiliser des filtres personnalisés, ajoutez des balises AWS à vos volumes FSx for ONTAP qui correspondent à vos besoins, telles que des balises pour les projets, les équipes ou les unités commerciales.

Pour plus de détails sur le balisage, voir  https://docs.aws.amazon.com/whitepapers/latest/tagging-best-practices/what-are-tags.html["Que sont les tags ?"^] et  https://docs.aws.amazon.com/resourcegroupstagging/latest/APIReference/overview.html["Référence de l'API de balisage des groupes de ressources AWS"^].



[[volume-details]]
== Détails du volume

Le tableau de bord propose différents modes d'affichage pour vous aider à analyser vos indicateurs de stockage à différents niveaux de détail.



[[total-view]]
=== Vue totale

La vue Totale (par défaut) affiche les métriques combinées de tous les volumes correspondant à vos filtres sélectionnés. Elle vous offre un aperçu rapide des performances globales du stockage, y compris la capacité totale, les IOPS et le débit.

Utilisez cette vue pour :

* Comprendre les tendances générales
* Planifiez les besoins futurs en capacité
* Rapport sur la consommation totale de ressources par projet ou équipe




[[volume-view]]
=== Vue du volume

La vue Volume montre comment les volumes individuels fonctionnent au fil du temps. Elle affiche les 10 principaux volumes pour chaque indicateur. Cela vous aide à voir quels volumes utilisent le plus de ressources et comment ils se comportent pendant la période sélectionnée.

Utilisez cette vue pour :

* Identifiez ce qui ralentit les performances
+
** Identifiez les volumes de stockage qui pourraient nécessiter d'être redimensionnés
** Voyez quels projets ou charges de travail utilisent le plus de ressources






==== Indicateurs de volume affichés

Lorsque vous consultez les volumes individuels, le tableau de bord affiche les 10 volumes les plus importants par rapport au nombre total de volumes pour chaque indicateur :

* *Capacité volumique utilisée* : Affiche les volumes présentant la capacité actuellement utilisée la plus élevée.
* *IOPS* : Affiche les volumes présentant la moyenne d’IOPS la plus élevée durant la période sélectionnée.
* *Débit* : Affiche les volumes présentant le débit moyen le plus élevé durant la période sélectionnée.



NOTE: Le tableau de bord n'affiche que les 10 premiers volumes pour chaque indicateur. Si vous avez plus de 10 volumes, certains volumes pourraient ne pas être affichés dans la vue détaillée.

Lorsque les mêmes volumes apparaissent dans plusieurs indicateurs, le tableau de bord utilise les mêmes couleurs dans la légende afin que vous puissiez facilement suivre ces volumes à travers différents indicateurs.



==== Données de volume interactives

Survolez le graphique pour afficher les valeurs exactes à des moments précis. Cela vous aide à relier les variations de performance à des événements ou des périodes. Les données détaillées peuvent vous aider à identifier les problèmes de performance, à confirmer que les optimisations ont fonctionné et à expliquer l'utilisation des ressources à d'autres personnes.

Lorsque vous survolez une courbe de volume dans les graphiques, vous pouvez visualiser :

* *Capacité utilisée du volume* : Nom du volume, capacité utilisée à ce moment-là et capacité allouée
* *IOPS* : Nom du volume, IOPS moyennes sur la période et IOPS maximales sur la période
* *Débit* : Nom du volume, débit moyen sur la période considérée et débit maximal sur la période considérée
